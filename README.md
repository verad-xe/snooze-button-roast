One line roasting an alarm clock that rings at 6 AM on a Saturday: the clock is an intern desperate for a promotion, so it gets one — head of frozen peas, effective immediately.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/snooze-button-roast-out python3 main.py
cat /tmp/snooze-button-roast-out/entry.txt
```

The program writes a single line of at most 200 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
